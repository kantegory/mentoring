# 17_adaptive_example: Адаптивность

Демонстрация приемов адаптивной верстки на Bootstrap 5:
- Сетка Grid System и брейкпоинты (`col-sm`, `col-md`, `col-lg`);
- Flexbox-утилиты для выравнивания и позиционирования;
- Управление видимостью блоков на различных разрешениях экранов (`d-none`, `d-md-block`).
