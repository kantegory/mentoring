# 27_simple_spa_example: Пример простого SPA приложения

В этом примере написан код для реализации SPA-приложения на чистом JavaScript и Bootstrap 5 с двумя разными вариантами клиентского роутинга:
- `history` — использование History API;
- `hash` — использование хэша в URL.

## Просмотр

Откройте `index.html` в браузере.
