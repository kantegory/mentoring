# 08_themization_example

Демонстрация динамического переключения тем оформления страницы (light, dark, blue, pink) с помощью JavaScript и переключения связанных CSS-файлов.

## Структура

- `index.html` — разметка интерфейса с селектором/кнопками смены темы;
- `styles/main.css` — базовые стили макета;
- `styles/light.css`, `styles/dark.css`, `styles/blue.css`, `styles/pink.css` — палитры и стилевые переменные для каждой темы.

## Просмотр

Откройте `index.html` в любом браузере.
