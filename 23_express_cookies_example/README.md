# 23_express_cookies_example

Пример работы с HTTP-куками (cookies) на стороне сервера с использованием Express и middleware `cookie-parser`.

## Возможности примера

- Установка стандартных кук с атрибутами безопасности (`httpOnly`, `maxAge`);
- Чтение приходящих кук из заголовков запроса (`req.cookies`);
- Работа с подписанными куками (`signed cookies`) с использованием секретного ключа для предотвращения модификации клиентом.

## Установка и запуск

```bash
npm install
npm start
```
