# 02_js_examples

Базовые примеры работы с JavaScript в браузере. В директории собраны демонстрации основных концепций и синтаксических конструкций языка:

- `conditions.html` — ветвления и условные операторы (`if`, `else`, тернарный оператор, `switch`);
- `cycles.html` — циклы (`for`, `while`, `do-while`, обход массивов);
- `functions.html` — функции (function declaration, function expression, стрелочные функции, параметры по умолчанию);
- `classes.html` — объектно-ориентированное программирование в ES6: классы, конструкторы, методы, геттеры/сеттеры и наследование;
- `index.html` — общая индексная страница со ссылками на демонстрационные примеры.

## Запуск

Примеры не требуют сборщиков или сервера. Достаточно открыть любой из `.html` файлов напрямую в браузере и открыть консоль разработчика (DevTools).
