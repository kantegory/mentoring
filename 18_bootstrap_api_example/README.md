# 18_bootstrap_api_example: Работа с JSON-сервером

Пример клиентского веб-приложения на Bootstrap 5 и чистом JavaScript, взаимодействующего с REST API на базе `json-server` и модуля авторизации `json-server-auth`.

## Установка зависимостей

Мы используем средний слой для авторизации в JSON-server. Документация доступна тут: https://www.npmjs.com/package/json-server-auth

```bash
npm install
```

## Запуск

```bash
npm start
```
