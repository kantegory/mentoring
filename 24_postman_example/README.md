# 24_postman_example

Пример экспортированной коллекции запросов Postman (`Postman Documentation Sample.postman_collection.json`).

## Что демонстрирует пример

- Структурирование запросов по папкам и ресурсам REST API;
- Использование переменных окружения и коллекций (`{{baseUrl}}`);
- Документирование заголовков, параметров и примеров ответов;
- Написание тестов и валидация статус-кодов ответов на вкладке Tests.

## Использование

Импортируйте файл `.json` в десктопное приложение Postman или веб-версию.
