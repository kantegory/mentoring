# 06_bootstrap_example

Примеры верстки страниц и использования базовых UI-компонентов фреймворка Bootstrap 5, подключенного через CDN.

## Файлы примера

- `index.html` — демонстрация типовой структуры страницы, навигационной панели (Navbar), карточек (Card) и кнопок;
- `second.html` — дополнительная страница с примерами форм, таблиц и типографики.

## Просмотр

Файлы не требуют сервера или сборки. Достаточно открыть `index.html` или `second.html` в браузере.
