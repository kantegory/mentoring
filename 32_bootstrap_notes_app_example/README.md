# 32_bootstrap_notes_app_example: Пример UI приложения для заметок на Bootstrap

Пример верстки адаптивного пользовательского интерфейса приложения заметок на базе Bootstrap 5.

Включает:
- Разметку карточек заметок с тегами и статусами;
- Навигационную боковую панель (Sidebar);
- Модальные окна создания и редактирования заметок;
- Кастомные стили (`notes.css`, `styles.css`).

## Просмотр

Откройте `index.html` или `notes.html` в браузере.
