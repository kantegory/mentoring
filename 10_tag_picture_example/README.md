# 10_tag_picture_example

Демонстрация адаптивных изображений в HTML5 с помощью тега `<picture>`, атрибута `srcset`, медиавыражений (`media`) и современных графических форматов.

## Возможности примера

- **Каскадный fallback по форматам**: браузер выбирает первый поддерживаемый формат от более эффективного к классическому: `AVIF` → `WebP` → `JPEG` (базовый тег `<img>`);
- **Адаптивность по разрешению**: подмена тяжелого изображения на уменьшенную версию для мобильных и планшетных экранов (`media="(max-width: 1024px)"`).

## Современные форматы изображений и статус их поддержки

### 1. Текущий индустриальный стандарт:
- **AVIF (`image/avif`)**: современный формат на базе кодека AV1. Обеспечивает наилучшее сжатие (в среднем на 20-30% компактнее WebP при одинаковом визуальном качестве). На сегодняшний день поддерживается всеми современными браузерами (Chrome, Firefox, Safari с iOS 16 / macOS Ventura, Edge).
- **WebP (`image/webp`)**: универсальный легковесный формат от Google, ставший де-факто стандартом веб-графики (поддержка >97% браузеров).
- **JPEG / PNG**: классические форматы, используемые в качестве безопасного резервного варианта (fallback) в теге `<img>` для максимальной совместимости.

### 2. JPEG XL (`image/jxl`) и исторический контекст:
Формат **JPEG XL** задумывался как универсальный преемник устаревшего JPEG, предлагая отличный коэффициент сжатия, поддержку HDR, широкого цветового охвата и возможность сжатия существующих JPEG без потерь (lossless transcoding).

Однако в истории его внедрения возникла фрагментация:
- В начале 2023 года команда Google исключила экспериментальную поддержку JPEG XL из кодовой базы **Chromium / Blink**, посчитав, что формат не даёт достаточного прироста над AVIF для оправдания поддержки отдельного кодека.
- В то же время компания **Apple** внедрила полноценную поддержку JPEG XL в свою экосистему начиная с Safari 17, iOS 17 и macOS Sonoma.
- В **Firefox** поддержка присутствует за экспериментальным флагом конфигурации.

> **Вывод для продакшена**: из-за отсутствия поддержки JPEG XL в доминирующих движках Chromium (Chrome, Edge, Opera) использование `AVIF + WebP + JPEG (fallback)` остаётся наиболее надежным и эффективным решением для веб-разработки.

## Просмотр

Откройте `index.html` в браузере и протестируйте адаптивность через инструменты разработчика при разных размерах экрана и эмуляции различных устройств.
