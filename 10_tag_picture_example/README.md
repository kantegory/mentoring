# 10_tag_picture_example

Демонстрация адаптивных изображений в HTML5 с помощью тега `<picture>`, атрибута `srcset` и медиавыражений (`media`).

## Возможности примера

- Отдача оптимизированных современных форматов (AVIF, WebP) для браузеров с их поддержкой и автоматический fallback на стандартный JPEG;
- Адаптация разрешения и размеров картинок под ширину экрана и плотность пикселей устройства (retina).

## Просмотр

Откройте `index.html` в браузере и протестируйте адаптивность через инструменты разработчика при разных размерах экрана.
