# 21_vue3_plugins_example: Работа с готовыми решениями

В этой демке разбираемся, как подключать и настраивать сторонние библиотеки во Vue 3 на примере интеграции интерактивного календаря [FullCalendar](https://fullcalendar.io/).

## FullCalendar

FullCalendar — это функциональный плагин для отображения интерактивных календарей, расписаний и событий.

## Установка зависимостей и запуск

```bash
npm install
npm run dev
```

### Сборка

```bash
npm run build
```
