# 07_json_server_example

Пример быстрого создания мок-сервера REST API с помощью утилиты `json-server` и локального файла данных `db.json`.

Позволяет отрабатывать HTTP-запросы (GET, POST, PUT, PATCH, DELETE) без необходимости писать собственный бэкенд.

## Структура данных (`db.json`)

- `posts` — список статей/постов;
- `comments` — комментарии к постам;
- `profile` — профиль пользователя.

## Запуск сервера

```bash
npm install
npm test
```
Сервер будет доступен по адресу `http://localhost:3000`.
