# 25_node_ws_example

Пример организации двусторонней связи в реальном времени с использованием протокола WebSocket на базе Node.js (библиотека `ws`) и браузерного клиента.

## Структура

- `server.mjs` — сервер WebSocket на Node.js, обрабатывающий подключения, отправку и широковещательную рассылку (broadcast);
- `client.html` — клиентская страница для подключения к веб-сокету, отправки сообщений и логирования событий.

## Установка и запуск

```bash
npm install
npm start
```

Затем откройте `client.html` в одном или нескольких окнах браузера для проверки обмена сообщениями.
