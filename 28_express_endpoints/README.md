# 28_express_endpoints: Написание эндпоинтов на Express

В этом примере рассмотрим 2 способа реализации эндпоинтов на Express (без сторонних библиотек) с использованием TypeScript и современного рантайма `tsx`.

В репозитории приведены два файла:
- `app.ts` — объявление эндпоинтов напрямую через методы объекта приложения `app.get`, `app.post` и т.д.;
- `router.ts` — модульная организация маршрутов через `express.Router()`.

## Запуск

```bash
npm install
npx tsx app.ts
# или
npx tsx router.ts
```
