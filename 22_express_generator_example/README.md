# 22_express_generator_example

Примеры генерации структуры серверных веб-приложений с помощью официальной утилиты `express-generator`.

## Варианты конфигураций

- `defaulName/` — стандартный проект Express со статическими файлами и базовыми маршрутами;
- `templates_example/` — проект с подключением шаблонизатора Twig (`.twig`) для серверного рендеринга представлений;
- `no-view-example/` — сервер для REST API без использования шаблонизаторов.

## Запуск любого из вариантов

Перейдите в соответствующую папку и выполните:

```bash
npm install
npm start
```
