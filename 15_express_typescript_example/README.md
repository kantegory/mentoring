# 15_express_typescript_example

Шаблон серверного приложения на Node.js с использованием Express и TypeScript, структурированный по трехуровневой архитектуре (маршруты, контроллеры, ядро).

## Структура каталогов

- `src/core/` — инициализация сервера и общие модули;
- `src/routes/` — маршрутизация запросов;
- `src/controllers/` — бизнес-логика и обработка запросов;
- `tsconfig.json` — параметры компиляции TypeScript.

## Установка и запуск

```bash
npm install
npm run dev
```
