# 09_svg_sprite_example

Пример эффективной работы с векторной графикой с использованием SVG-спрайтов (`sprite.svg`) и конструкции `<svg><use href="..."></use></svg>` в комбинации с Bootstrap 5.

## Преимущества подхода

- Уменьшение количества сетевых HTTP-запросов за счет объединения всех иконок в один файл;
- Возможность гибкой стилизации векторных иконок через CSS (`fill`, `stroke`, `currentColor`).

## Просмотр

Откройте `index.html` в браузере.
