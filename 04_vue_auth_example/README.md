# 04_vue_auth_example

⚠️ ПРИМЕР УСТАРЕВШИЙ
Оставлено в качестве исторического примера

Пример реализации клиентской аутентификации и регистрации пользователей на базе стека Vue 2, Vuetify 2, Vue Router и Axios. Содержит страницы авторизации (`SignIn.vue`), регистрации (`SignUp.vue`) и защищенные маршруты.

## Установка и запуск

> Для запуска рекомендуется использовать версию Node.js, зафиксированную в `.nvmrc` (v16).

```bash
npm install
npm run serve
```

### Сборка для продакшена

```bash
npm run build
```

### Линтинг

```bash
npm run lint
```
