# 26_express_rabbitmq: Пример взаимодействия микросервисов через RabbitMQ

Требования:
- Docker (не ниже версии 25.0.3);
- Node.js (версия, зафиксированная в `.nvmrc`);
- npm.

## Сервисы примера

- `cart.ts` — сервис корзины пользователей;
- `payment.ts` — сервис обработки платежей;
- `stock.ts` — сервис складского учета товаров.

## Взаимодействие через очереди сообщений

1. Сервис корзины инициирует оформление заказа и отправляет событие в RabbitMQ;
2. Сервисы склада и платежей асинхронно получают сообщение, валидируют остатки и обрабатывают оплату;
3. Результаты публикуются в соответствующие очереди ответов.

## Запуск

Запуск RabbitMQ через Docker Compose:

```bash
docker compose up -d
```

Установка зависимостей и запуск сервисов:

```bash
npm install
npm run dev
```
